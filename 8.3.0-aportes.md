### Funcionalidad 1 — UC-009: historial propio de pedidos filtrado por estado

**Descripción:** endpoint `GET /api/orders/me?status=...` autenticado mediante JWT; identifica al comprador por su token, permite `PENDIENTE`, `CONFIRMADO` y `CANCELADO`, y utiliza consulta de repositorio por usuario y estado.

**Caso de uso y criterios de aceptación:** [FSD UC-009](docs/fsd/UC-009-historial-pedidos-filtrado.md), CA-01 a CA-07. Con JWT válido devuelve solo los pedidos propios del estado solicitado; sin coincidencias devuelve `200 []`; sin token se bloquea (en ejecución HTTP respondió 403); estado inválido se valida como HTTP 400.

**Archivos relevantes:**
- `backend/umss-market-api/src/main/java/bo/umss/market/umss_market_api/infrastructure/controllers/MyOrdersController.java`
- `backend/umss-market-api/src/main/java/bo/umss/market/umss_market_api/application/usecases/GetOrdersUseCase.java`
- `backend/umss-market-api/src/main/java/bo/umss/market/umss_market_api/infrastructure/config/SecurityConfig.java`
- `backend/umss-market-api/src/test/java/bo/umss/market/umss_market_api/application/usecases/GetMyOrdersUseCaseTest.java`
- `backend/umss-market-api/src/test/java/bo/umss/market/umss_market_api/infrastructure/controllers/MyOrdersControllerTest.java`

**Evidencia:** registro HTTP 201, login con JWT, consulta por estados HTTP 200, pedido real con cambios PENDIENTE → CONFIRMADO → CANCELADO y exclusión del pedido en estados diferentes al actual.

### Funcionalidad 2 — UC-010: catálogo REST paginado

**Descripción:** `GET /api/catalog/publications?page=0&size=2` con filtros opcionales (texto, tipo, precio, tienda, categoría y disponibilidad), validación de parámetros y metadatos. Reutiliza el adaptador del catálogo y mantiene `GET /api/publications`.

**Caso de uso y criterios de aceptación:** [FSD UC-010](docs/fsd/UC-010-catalogo-rest-paginado.md), CA-01 a CA-07. Página base cero, tamaño 1–50, orden determinista, metadatos completos, parámetros inválidos HTTP 400 y respuesta sin campos internos.

**Archivos relevantes:**
- `backend/umss-market-api/src/main/java/bo/umss/market/umss_market_api/infrastructure/controllers/PagedPublicationsController.java`
- `backend/umss-market-api/src/main/java/bo/umss/market/umss_market_api/application/dto/PagedPublicationItem.java`
- `backend/umss-market-api/src/main/java/bo/umss/market/umss_market_api/application/dto/PagedPublicationsResponse.java`
- `backend/umss-market-api/src/test/java/bo/umss/market/umss_market_api/infrastructure/controllers/PagedPublicationsControllerTest.java`

**Evidencia:** HTTP 200, 2 ítems, 105 publicaciones, 53 páginas; página negativa HTTP 400; pruebas de compatibilidad y contrato OpenAPI actualizado.
